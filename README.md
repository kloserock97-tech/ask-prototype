# ась? — ИИ-ассистент за рулём

Рабочий прототип голосового ИИ-ассистента для поездки на машине: телефон на торпедо,
трасса М‑11, водитель спрашивает про ключевую ставку ЦБ.

**Открыть с телефона:** https://kloserock97-tech.github.io/ask-prototype/

*A working voice-assistant prototype for use while driving. Russian UI.*

## Сценарий

Коснитесь нижней половины экрана и спросите: «какая ставка ЦБ на месяц?»

- ась слушает (живые субтитры), думает («листаю пресс‑релизы ЦБ») и отвечает вслух;
  на экране — одна цифра «14% до 18 декабря» и источник;
- понимает продолжения: «подробнее» / «а что в декабре?», «сохрани», «повтори», «стоп»;
- на «а вклад открывать?» не советует, на непонятное переспрашивает выбором из двух.

Данные — на 27 октября 2026: решение Банка России от 23 октября, следующее заседание 18 декабря.

## Как выглядит

Композиция повторяет один референс — экран «Expiratory Volume» (Pinterest): чёрное поле
в мелкую точку, полутоновая сфера, цифра из точек с короткой подписью и светящаяся панель внизу.

- **Поле точек** (`src/app/field.ts`, один WebGL-шейдер). Сфера, цифра и «капель» точек между
  ними — это те же точки сетки, только зажжённые: сфера освещена сверху справа, цифра набрана
  тонким шрифтом по одной точке на клетку. Раскладку задаёт CSS через пустые блоки-заглушки,
  шейдер берёт их координаты, поэтому телефон, планшет, альбомная ориентация и рамка на
  десктопе получают одну композицию.
- **Сфера — это ась, без лица.** Говорите — по ней рассыпаются огоньки и она чуть растёт;
  «думаю» — сверху льётся синий свет и по сфере бежит полоса; ась отвечает — от центра
  расходятся кольца в такт голосу; пауза — сфера ложится серой полосой. «Капля с глазами»
  (squishmoji) — в меню, для сравнения.
- **Панель:** по углам решение ЦБ (23.10) и следующее заседание (18.12), в центре подсказка
  с пирамидкой из точек, ниже ползунок: «луна» → лаймовая линия → пунктир к кольцу. Линия
  растёт, пока вы говорите, и идёт по записи, пока ась отвечает. Внизу — круглая кнопка
  и пилюля с белым кругом; всё остальное на экране — одна большая кнопка «спросить / перебить».
- **Голос — заранее записанные реплики** (`public/voice/*.mp3`, тексты — `voice-src/lines.tsv`,
  сборка — `scripts/make-voice.sh`: Piper, голоса на CC0-датасетах). Громкость записи зажигает
  точки, позиция двигает лаймовую линию. Нет файла — читает голос браузера.

## Не открывая приложение

- **Слово «ась»** (меню → «слушать слово „ась“»): в покое ась ждёт слово и слушает вопрос;
  «ась, какая ставка?» одной фразой — сразу ответ. Распознавание в браузере облачное,
  в продукте здесь нужен локальный детектор слова.
- **Ярлыки на иконке (Android):** «Добавить на главный экран», долгое нажатие на иконку —
  «Ставка ЦБ» или «Спросить голосом» (`manifest.webmanifest`).
- **«Привет, Siri, ась»:** приложение «Команды» → «Открыть URL» с адресом
  `https://kloserock97-tech.github.io/ask-prototype/?ask=rate` и фразой «ась».
- **Виджет и Dynamic Island** — `#/widget`: так это выглядит в нативном приложении — касание
  виджета, ответ поверх домашнего экрана, итог в «острове».

## Взаимодействие

- **Больше половины экрана — одна зона касания.** В покое — спросить, во время ответа —
  перебить, на паузе — продолжить. Свайп вниз — стоп. Касание засчитывается при 60–700 мс
  и сдвиге до 12 px, мультитач и касания сразу после смены экрана отбрасываются —
  защита от тряски и ладони.
- **Живая подсветка снизу** (`src/app/aurora.ts`): свет поднимается от нижнего края сквозь
  рифлёное стекло. Высота следует за громкостью голоса водителя (Web Audio, полоса
  150 Гц – 4 кГц, порог шума подстраивается под салон), во время «слушаю» тянется к пальцу,
  при «думаю» по ней бежит волна, при ответе она пульсирует по словам, на паузе гаснет до серого.
  Яркость меняется не больше чем на ±8 %: слоги идут 4–5 раз в секунду, а WCAG 2.3.1
  разрешает не больше 3 вспышек.
- **Три способа спросить:** голосом, касанием (без микрофона — ась задаёт вопрос за вас) и демо.
- **Ситуации в дороге** из меню: навигатор говорит, шлагбаум, пропала сеть, звонок —
  ась замолкает и продолжает с начала фразы.
- Экран не гаснет, пока приложение открыто (Wake Lock).

## Цвет под свет

Две темы:

| | тёмная (основная) | солнце |
|---|---|---|
| фон | `#000000`, сетка точек | `#FFFFFF`, сетка точек |
| точки и текст | `#FFFFFF` | `#05060F`, точки крупнее |
| панель | `#04051A` с лавандовым свечением по краю | сплошной кобальт `#1F28D6`, обводки 2 px |
| акцент | лайм `#D8F26A` | лайм `#E8FF6B` |

- под прямым солнцем тёмный экран превращается в зеркало, поэтому есть «солнце»: позитивная
  полярность, без свечений и полупрозрачности;
- где браузер даёт датчик освещённости (Chrome на Android), «солнце» включается само;
  переключить можно в меню.

## Концепт

Из меню доступны все экраны концепта (ставка, Half‑Life 3, корнер‑кейсы, сводка поездки),
user flow, Dynamic Island поверх навигатора и визуальный гайд.

## Как устроено

- Vite + TypeScript, без фреймворка; распознавание речи и синтез — средствами браузера.
- Пружины считаются физически и запекаются в CSS `linear()` (`src/motion.ts`), анимируются
  только transform и opacity, `prefers-reduced-motion` уважается.
- В концепте 3D — персонаж, объёмные цифры и предметы смоделированы и отрендерены в Blender,
  в сайте — WebP с прозрачностью. В рабочем приложении их заменили точки (Canvas 2D и SVG).

```bash
npm install
npm run dev
npm run build
```
