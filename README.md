# GRIF · В дороге — ИИ-компаньон с режимом для машины

Рабочий прототип: обычный ИИ-чат на телефоне (раскладка как у ChatGPT и Grok), у которого есть
режим «В дороге». Пример поездки: Лада Гранта, телефон на торпедо, трасса Москва — Петербург;
водитель спрашивает про ключевую ставку ЦБ и слухи о Half-Life 3.

**Открыть с телефона:** https://kloserock97-tech.github.io/ask-prototype/

*A working prototype of a chat AI companion with a hands-free driving mode. Russian UI.*

## Сценарий

1. **Чат.** Спросите текстом или нажмите «Ставка ЦБ» / «Half-Life 3». Ответ полный, части
   помечены: факт, прогноз ЦБ, мнение аналитиков, слух; под ответом источники и «На потом».
2. **Вход в режим.** «В дорогу» есть в подсказках, в меню и в листе «+». Сигналы машины
   изображаются через меню → «Сигналы машины · демо»:
   - Bluetooth «LADA» (машина стоит) — лист «Вы в машине?»;
   - движение больше 20 км/ч — плашка с отсчётом 3 с и «Отмена»;
   - NFC-метка на держателе — режим включается сразу.

   Можно включить настоящий GPS: режим включится сам, если поехать.
3. **В дороге.** Весь экран — одна кнопка: касание = спросить или пауза, свайп вниз — стоп.
   С микрофоном работают голос и слово «ась». Без микрофона касание произносит следующую реплику
   демо: ставка → «почему?» → «да» → «сохрани» → Half-Life 3 → «откуда слух?» → «сохрани» → «приехали».
4. **Остановка.** Сводка с сохранённым. Чат поездки сам закрепляется в меню; в нём расшифровка,
   полные ответы, отметки «Сохранено в дороге» и источники.

Меню «⋯» в режиме — что может случиться в дороге: пропала связь, звонок, «помолчи», нет микрофона.

Данные — на 28 октября 2026:
- ЦБ сохранил ставку 14% 23 октября; прогноз ЦБ на 2027 год — 12,5–13,5%;
- следующее заседание — 18 декабря (по одному источнику, сверить с cbr.ru);
- Half-Life 3: разработчик Valve обронил «HLX» на GameSoundCon 23 октября, Valve ничего не объявляла.

## Как выглядит

- **Чат** — тёмный интерфейс GRIF. Есть только чат: меню со списком разговоров,
  закреплёнными и поиском; голосовые разговоры помечены волной, как у Grok. Отдельной ленты
  или раздела для сохранённого нет.
- **«В дороге» — концепция «Горизонт»** (`src/grif/horizon.ts`). Низ экрана — линия горизонта
  из полутоновых точек, свет поднимается от края. Высота и движение света показывают состояние,
  и его видно боковым зрением:

  | Состояние | Свет |
  |---|---|
  | слушает | поднимается от вашего голоса |
  | ищет | по линии бежит пятно |
  | говорит | пульсирует на слогах |
  | пауза | опускается до тонкой линии |
  | нет связи | янтарный пунктир |

  В центре одна опорная вещь — «14%» или метка «СЛУХ» — и фраза, которая звучит: сказанное
  светлеет. Внизу одна кнопка 88 px.
- **Ответ — куски по 10–15 с**, каждый заканчивается одним вопросом («Рассказать почему?»).
  Работают команды «короче», «повтори», «сохрани», «стоп», «пауза», «продолжай», «помолчи»,
  «сравни», «откуда», «приехали».
- **Голос** — записанные реплики (`public/voice/g-*.mp3`, Piper); без записи читает браузер.
  Сигналы «слушаю», «готово», «стоп».

Правило входа: упростить экран система может сама, а микрофон включается только с согласия.

## Как устроено

- `src/grif/grif.ts` — приложение (чат, меню, листы, режим, сводка);
- `src/grif/talk.ts` — реплики, куски ответов, метки, разбор команд;
- `src/grif/horizon.ts` — шейдер WebGL2;
- `src/app/ears.ts`, `src/app/wake.ts`, `src/app/earcon.ts` и `src/voice.ts` — распознавание речи,
  слово «ась», звуковые сигналы и голос.

Прежние версии: `#/v9` — голосовой экран «ась?», `#/screens` — концепт и user flow.

```bash
npm install
npm run dev
npm run build
```

## Не открывая приложение

- `?drive=1` — сразу режим «В дороге», `?ask=rate` — сразу спросить про ставку.
- Ярлыки на иконке (Android, «Добавить на главный экран») и «Команды» на iPhone с этими адресами.
