# ась? — ИИ-ассистент за рулём

Концепт голосового режима ИИ-ассистента для поездки на машине: телефон на торпедо,
трасса М‑11, два вопроса — прогноз ключевой ставки ЦБ на месяц и свежие слухи о Half‑Life 3.
Живой прототип: экраны, корнер‑кейсы, user flow и визуальный гайд.

**Смотреть с телефона:** https://kloserock97-tech.github.io/ask-prototype/

*A voice-mode concept for an AI assistant used while driving. Russian UI.*

## Что внутри

- **Три сценария, 21 экран.** Ставка ЦБ (день), слухи о Half‑Life 3 (ночь), корнер‑кейсы:
  навигатор перебил, шлагбаум, нет сети, ограниченный интернет, не расслышал, звонок,
  усталость, SOS и сводка поездки на стоянке.
- **Голос.** Ась читает свои реплики вслух через синтез речи браузера; на каждом слове
  свечение за стеклом получает толчок громкости.
- **User flow** — все состояния и переходы, узел открывает экран.
- **Вне приложения** — Dynamic Island поверх навигатора: пиксельные мордочки, остров
  перетекает пружиной между компактным и развёрнутым видом.
- **Гайд** — правила, цвет, шрифт, позы персонажа, 3D‑предметы, живой шейдер, движение.

## Как устроено

- **Принципы — из исследований вождения.** Взгляд на экран до 2 с, на экране до 30 знаков,
  текст от 28 pt, не больше двух кнопок по 112 pt в нижней трети, голос главный.
- **Шейдер «Голос за стеклом»** (`src/gl/glass.ts`): кобальтовое свечение за вертикальным
  рифлёным стеклом — полосы работают как линзы. Параметры плавно подтягиваются к состоянию
  (жду / слушаю / думаю / говорю / пауза / SOS), рендер в половинном разрешении ради батареи.
- **Движение** (`src/motion.ts`): пружины считаются физически и запекаются в CSS `linear()`,
  поэтому идут через Web Animations API, а не JS‑цикл. Анимируются только transform и opacity,
  нажатие — `scale(0.97)` за 160 мс, уход быстрее появления, ответ приходит событием
  (вспышка → карточка на пружине → покой, ~600 мс), `prefers-reduced-motion` уважается.
- **3D** — персонаж, объёмные цифры и предметы смоделированы и отрендерены в Blender (Cycles),
  в сайте лежат как WebP с прозрачностью, всего ~200 КБ.
- **Экраны — данные** (`src/data/screens.ts`): один список питает плеер, user flow и гайд.

## Запуск

```bash
npm install
npm run dev      # открыть адрес из консоли, с телефона — по IP компьютера
npm run build
```

## Prior art

Визуальный язык — по мотивам гайдов Dodo Brands и Дринкита (тихий интерфейс, один громкий
цвет, эмоция в 3D, графический алфавит). Идея рифлёного стекла поверх света подсмотрена
у компонента Cobalt Louvre (OriginKit); шейдер написан заново под голосовой индикатор.
